DeepSeek-V4 Training Stack from Scratch

How it was built

Part 1: Manifold-Constrained Hyper-Connections

Expand the residual stream into n_hc streams, generate the input, residual and output mixing maps dynamically from the input, project the residual map onto the doubly stochastic manifold with Sinkhorn-Knopp, wrap any layer in an mHC block, and measure the signal norm across depth with and without the constraint (report section 2.2).

Part 2: Muon with Hybrid Newton-Schulz

Write the Muon optimizer of report Algorithm 1: one Newton-Schulz iteration, the hybrid ten-step orthogonalisation, the momentum buffer with the Nesterov trick and the RMS rescaling to 0.18, the Muon/AdamW parameter split, and one optimizer step with weight decay for both groups (report section 2.4 and 4.2.2).

Part 3: DeepSeekMoE with Routing Stability

Build the MoE layer of DeepSeek-V4: sqrt-softplus affinities with top-k selection, auxiliary-loss-free load balancing through a per-expert bias plus the slight sequence-wise balance loss, hash routing for the first layers, shared experts, SwiGLU clamping, and anticipatory routing that reuses routing indices computed with older parameters (report sections 2.1, 4.2.2 and 4.2.3).

Part 4: FP4 Quantization-Aware Training and MTP

Fake-quantize expert weights to MXFP4 (E2M1 elements with power-of-two block scales) and the remaining weights to FP8 E4M3 with straight-through gradients, as in the report's quantization-aware training, then build the multi-token-prediction module and its loss (report sections 2.1, 4.2.2 and 5.2.1).

Part 5: Train a Tiny V4-Style Model

Assemble a tiny decoder from the parts (mHC-wrapped attention and MoE blocks, shared embedding and head, an MTP module), generate synthetic token data with learnable structure, and train it twice under one seed, with the stability mechanisms off and on, reporting loss curves, loss-spike counts, routing and clamping diagnostics, the optimizer's update RMS, and an FP4 quantization-aware fine-tuning phase.
